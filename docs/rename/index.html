模块改名工具

打开 Rex 模块 .js，改编号（id）、名称（title）、版本（version）后另存。文件只在本机读取，不上传。作者：Bolinxxlin

在 Rex 的模块页点开模块 →「导出」存到「文件」，再从这里选它。

怎么选
  • 只想改名字：改名称，编号不动 → 导入后覆盖原本那个，名字换掉。
  • 想两个同时留着：编号按「加 .copy」，名称按「加（备用）」→ 导入后列表里有两个。
  • 改过的模块是本机版，不会自动更新；链接版一更新，名字会被改回去。
  • 首页的行记的是模块网址和功能名，改名称不影响首页；改了编号的副本，首页要另外加行才会用到。
  • 第一行是 REXENC 的是加密模块，改不了。
