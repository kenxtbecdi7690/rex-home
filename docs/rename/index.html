模块 JS 改名工具

打开 Rex 模块 .js 或首页包 .rex，改编号（id）、名称（title）、版本（version）后另存；首页包里的行会跟着改成新编号。文件只在本机读取，不上传。作者：Bolinxxlin

模块：在 Rex 的模块页点开模块 →「导出」存到「文件」。首页包：用首页导出工具导出的 .rex，或别人给的。

包里的模块（导入时会一起装进 Rex）：

怎么选
  • 只想改名字：改名称，编号不动 → 导入后覆盖原本那个，名字换掉。
  • 想两个同时留着：编号按「加 .copy」，名称按「加（备用）」→ 导入后列表里有两个。
  • 改过的模块是本机版，不会自动更新；链接版一更新，名字会被改回去。
  • 首页的行记的是模块网址和功能名，改名称不影响首页；改了编号的副本，首页要另外加行才会用到。
  • 第一行是 REXENC 的是加密模块，改不了。
  • 首页包 .rex：包里的模块改了编号，首页里用到它的行会一起改成新编号，导入后首页照样能用，而且不会盖掉 Rex 里原本的同名模块。只指向网址的模块（链接版）不在包里，不用改。
