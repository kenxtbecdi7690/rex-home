Rex首页导出工具

2026.10.24 版 · 作者：Bolinxxlin

iPhone 的 Rex 没有「导出首页」。这个网页工具帮你把自己调好的首页导出成 .rex 文件，发给朋友，对方导入就有一样的首页。用 Safari 打开就能用，不用安装。

打开工具 kenxtbecdi7690.github.io/rex-home/builder/

能做什么

  • 导出首页：从 Rex 备份读出你的首页
  • 编辑首页：开关、调整顺序、改设置、加行
  • 一键重置：回到 Rex首页的初始首页
  • 空白模板：跟 Rex 的空白模板一样，再自己加行
  • 打开别人的 .rex：照着改成自己的

教学一：导出自己的首页

  1. Rex 设置 →「iCloud」→「备份与还原」→「导出本机备份」，存到「文件」App
  2. 在「文件」点备份，解压
  3. 依序打开 payload → homes → configs
  4. 选没有 .sync、几 KB 的那个 .json
  5. 打开工具 → 点「打开 .rex／备份」→ 选它
  6. 在「首页名称」填个名字 → 点「导出首页」
  7. 得到 RexHome.rex

存成 .zip 的话，在「文件」里长按 → 重新命名为 .rex

教学二：别人怎么导入

  1. 把 RexHome.rex 存到「文件」
  2. 在 Rex 长按打开菜单 →「导入配置」→ 选它
  3. 再到「切换配置」选它，就好了

注意

  • 只在你的手机里读取，不会上传
  • 只读首页设置，不碰账号资料
  • 整个备份里有你的资源库账号，不要发给任何人；只发导出的 RexHome.rex
  • 按错了都能点「撤销」
