Rex 首页导出与导入

2026-10-31 更新 · 对应工具 2026.10.30 · 作者：Bolinxxlin

先选现成首页，或打开自己的首页／备份；调整后导出 首页名称.rex，再用 Rex 导入。iPhone、iPad、Mac 都能使用网页工具。Forward 的 .fwd 与备份也能直接转成 Rex 首页。

正文用简体中文；「」内保留工具界面原文。图均为示意图，App 菜单可能随版本不同。

开启 Rex 首页导出工具
① 选成品首页② 开现有首页③ 编辑各行④ 选尺寸导出 ⑤ iPhone／iPad 导入⑥ Mac 导入⑦ Forward 转换验证与疑难

① 没有文件？先选成品首页

  1. 打开上方工具，找到「成品首页」菜单。
  2. 点击下列任一项；载入会替换目前编辑内容，要保留旧版本请先导出。
  3. 等名称与各行更新，再往下编辑。菜单会回到「选一个直接载入……」，这是正常的。
四大平台：爱奇艺＋腾讯＋芒果＋优酷从四平台首页配置开始。
豆瓣＋B站榜单从豆瓣与 B 站榜单配置开始。
MakkaPakka 快速版从 MakkaPakka 快速配置开始。

载入需要网络。出现「载入不了成品」时，先检查网络；也可到 platform-home 分支下载 PlatformHome.rex、DoubanBilibili.rex 或 MakkaFast.rex，再用「打开 .rex／.fwd／备份」读取。

② 打开自己的首页或备份

iPhone／iPad：从 Rex 备份取出

  1. 在 Rex 设置进入「iCloud」，找到备份区域，按「导出本机备份」。此路径依仓库既有说明，未经本轮 App 实机确认。
  2. 在系统分享菜单保存到「文件」，记下位置，例如 iCloud Drive 或「我的 iPhone」。不必安装 ES 文件浏览器。
  3. 回网页工具，按「打开 .rex／.fwd／备份」选刚存的备份 zip，不用解压。
  4. 若出现多首页菜单，选要导出的首页，核对名称、行数与行名。名称读不到时，手动填「首页名称」。

已经有文件

  • Mac 导出或朋友分享的 .rex：同一开启按钮选档，电脑也可直接拖进网页。
  • Forward 的 .fwd／备份 zip：同一按钮直接开启，详细步骤见第 ⑦ 段。

进阶：只有个别首页 JSON

从 Rex 备份的 payload → homes → configs 选不含 .sync 的首页 .json。.sync.json 是同步记号；不要只看文件大小或选「最新修改」的文件，因为可能包含已删首页的旧档。

优先开完整备份 zip，让工具列出首页；工具不支持 .rar、.7z。不要把整份备份寄给别人，备份内含账号等个人资料。

③ 编辑名称、顺序与各行

  1. 「首页名称」填入如「我的首页」。按「换头像」选图，会裁成 333×333 PNG；「用默认头像」移除自订图。
  2. 每行开关控制显示；按「↑／↓」上下移动。
  3. 按「设置」修改「标题」、「副标题」与该模块提供的地区、类型等选项，完成按「收起」。
  4. 底部选择模块后按「＋ 添加一行」。同一模块可加入多次，例如日本与韩国各一行。
  5. 要移除行，在该行「设置」内按「删除这一行」。

标示「其他模块」的行保留来源设置，可调整标题、副标题、开关、顺序；不能在此编辑资料参数。Rex 内仍要具备所用的模块与必要设置。

「一键重置」回工具初始首页；「空白模板」从官方轮播开始；「默认配置」是 Rex 默认的 14 行。三者都会替换目前内容，刚按完可立即点信息中的「撤销」。一般编辑、删除与载入成品没有通用的复原键，请先导出留底。

④ 选版面尺寸，再导出

在「版面尺寸」选适合的选项，再按「导出首页」。以下以「首页名称」填「我的首页」为例：

界面选项原文下载文件名
原样（手机、iPad）我的首页.rex
Mac 中尺寸（全宽行放大）我的首页-Mac.rex

主工具不再固定输出 RexHome.rex。不合法的文件名字元会移除，清理后空白才用 RexHome 当后备名称。Mac 也可选「原样」保留来源尺寸。

「原样」不会把 Mac 首页缩回手机尺寸；Mac 中尺寸会加高支持的全宽格子，避免对已加高的文件重复套用。一般首页至少开一行，否则会显示「至少要开启一行。」

⑤ iPhone／iPad 导入

  1. 在 Safari 下载项目或「文件」找到刚导出的 .rex；朋友收到文件，也先保存到「文件」。
  2. 点文件并选 Rex 开启；若没有 Rex 选项，改到 Rex 长按打开配置菜单 →「导入配置」，挑选该文件。
  3. 在「切换配置」确认并选新首页，检查名称、行顺序及相关模块。

GitHub Pages 正常会下载 .rex。只有特殊嵌入环境存成 .zip 时，才把工具导出的首页包扩展名改成 .rex，避免留下 .rex.zip。不要改整份备份 zip，也不要靠改扩展名转换 .fwd。

⑥ Mac 导出与导入

  1. 用浏览器开相同工具；选成品首页，或开启／拖入自己的 .rex、.fwd、备份 zip。
  2. 有多个首页就先挑选；编辑后可选「Mac 中尺寸（全宽行放大）」。
  3. 按「导出首页」，到浏览器设置的下载位置（通常是「下载项目」）找到 首页名称-Mac.rex；选原样则没有 -Mac。
  4. 用 Rex 的「导入配置」选档，再切换新首页。

Mac 的「导入配置」确切位置尚未经本轮实机确认，不指定左侧栏或菜单位置。仓库既有说明指出 Mac Rex 可直接导出首页；本教学示范的是网页工具流程。

⑦ Forward .fwd／备份转成 Rex

准备 Forward 导出的 .fwd，或 Forward 设置导出的备份 zip；备份不用解压。App 导出备份菜单的确切位置未经本轮实机确认。

A．要编辑各行、选尺寸：用主工具

  1. 开 Rex 首页导出工具 →「打开 .rex／.fwd／备份」选档。
  2. 备份有多个首页时，在出现的首页菜单挑选；确认名称、行数与行名。
  3. 名称、头像与各行读入后，依第 ③ 段编辑，再选尺寸。
  4. 按「导出首页」，得到 首页名称.rex 或 首页名称-Mac.rex，依第 ⑤／⑥ 段导入。

B．只需快速转换：用独立工具

  1. 开 Forward转Rex →「选择文件」。
  2. 选 .fwd 或 Forward 备份 zip；有多个首页时选「备份里的首页」。
  3. 核对首页及行数，可修改「首页名称」。
  4. 按「导出 RexHome.rex」，再用 Rex 导入。

两个工具文件名不同：主编辑器依首页名称命名；独立「Forward转Rex」目前仍固定输出 RexHome.rex，即使修改「首页名称」也一样。独立工具没有各行编辑或尺寸菜单。

要保留 Forward 格式？

使用 Forward 官方导出工具 ↗ 产生供 Forward 使用的 .fwd。本页两个 Rex 工具都输出 .rex，不输出 .fwd；不必先经官方工具，才能读取既有的 Forward 备份。

转换首页不会替你登录或迁移资源库账号，也不代表各行播放可用。第三方模块及必要参数仍需在 Rex 内设置。不要分享整份备份；分享首页包前，也请检查第三方行是否有个人网址或参数。

验证范围与常见问题

功能核对依据：main 22e1e8e 的主工具及独立转换工具。静态与程序层级检查、浏览器受阻情形另列于 PR。

  • 下载后找不到：查看浏览器下载清单与设置的位置，按首页名称找文件。
