Rex首页导出工具

2026.10.24 版 · 作者：Bolinxxlin

iPhone 的 Rex 没有「导出首页」。用这个网页工具，把你调好的首页导出成 RexHome.rex 发给朋友，对方导入就有一样的首页。Safari 打开就能用，不用安装。

打开工具 kenxtbecdi7690.github.io/rex-home/builder/
  1. 1导出备份
  2. 2找设置档
  3. 3用工具导出
  4. 4别人导入

1在 Rex 导出备份

Rex 设置 →「iCloud」→ 往下滑到「备份与还原」→ 点「导出本机备份」，存到「ES 文件浏览器」。

2找到首页设置档

  1. 在「ES 文件浏览器」找到 rex-backup-一串数字，点一下解压
  2. 依序打开 payload → homes → configs
  3. 选没有 .sync、几 KB 的 .json；有好几个就选修改时间最新的

只有 18 byte 的 .sync.json 是同步记号，选它工具会提醒你改选。

3用工具导出首页

  1. 点上方「打开工具」
  2. 点「打开 .rex／备份」→「浏览」→ 选「ES 文件浏览器」→ 选第 2 步的 .json
  3. 在「首页名称」填个名字，需要的话调整各行
  4. 点「导出首页」，得到 RexHome.rex

「浏览」里找不到 ES 文件浏览器：在 ES 里长按那个 .json → 分享 →「存储到文件」，再从「文件」选它。
存成 .zip 的话，在 ES 文件浏览器里长按 → 重命名为 RexHome.rex。

4发给别人，对方导入

  1. 把 RexHome.rex 发给对方，存到「ES 文件浏览器」
  2. 在 Rex 长按打开菜单 →「导入配置」→ 选它
  3. 再到「切换配置」选新的首页

其他功能

一键重置回到 Rex首页的初始首页
空白模板跟 Rex 的空白模板一样，再自己加行
编辑首页开关、排序、改设置、加行
撤销按错了都能点「撤销」

注意

  • 只在你的手机里读取，不会上传
  • 只读首页设置，不碰账号资料
  • 整个备份里有你的资源库账号，不要发给任何人；只发 RexHome.rex
