模块版本检查

打开 Rex 备份，或一次选多个模块 .js：看每个模块的编号和版本、查有没有新版、找出重复，逐个标「留／不留」再导出清单。文件只在本机读取，不上传；备份只读模块、订阅、首页三张表，不读账号、Cookie 和观看记录。作者：Bolinxxlin

备份：Rex 设置 →「iCloud」→「备份与还原」→「导出本机备份」。.7z 请先解压成 zip 或文件夹再压成 zip。

版本检查

到模块网址、订阅清单和 Bolinxxlin 的 GitHub 合集查最新版本号，和现在装的比。要连网；只读模块网址和订阅清单，备份不会传出去。

查完后，上面「有新版」那一栏会列出来，每个模块也会写「→ 新版本」。

怎么用

  • 编号相同：Rex 只会留一个，后装的盖掉先装的。两个都要留，就把其中一个「改编号」。
  • 名称相同、编号不同：两个本来就并存，只是列表里分不清。想分清就「名称加来源」，或删掉不用的那个。
  • 删之前看「首页」：正在被首页用的，删掉那几行会空白。
  • 留／不留：只是记号，帮你决定；按「导出『不留』清单」得到一份要在 Rex 删除的列表，照着删。工具不会删任何模块。
  • 有新版：先按「检查新版」。链接版到 Rex 模块页「刷新」；本机版用链接重装或重新导入首页包。
  • 链接版改名后会被更新改回去；只有本机版改名会一直有效。
  • 备份里的模块不能在这里直接改：先在 Rex 模块页「导出」那个模块，再把 .js 选进来改。
