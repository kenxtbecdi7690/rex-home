Rex首页导出工具

Rex首页导出工具2026.10.24

作者：Bolinxxlin

iPhone 的 Rex 没有导出，用这里从备份导出首页；也能把 Forward 的首页（.fwd 或 Forward 备份）转成 Rex 的。也可以打开别人的首页，或从默认首页开始，勾选行、调整顺序和设置，再导出分享。导出的首页读取 GitHub 上的加密脚本，不含明文。

Rex
头像
Forward 官方导出工具 ↗ 可打开 Mac 导出或别人分享的 .rex、Forward 导出的 .fwd，Rex 或 Forward 的备份（工具会自己找出首页设置），或 Rex 备份里的首页设置（payload/homes/configs 里没有 .sync 的 .json）。只在本机读取，不上传。用电脑（Mac）时也可以把档案直接拖进这个网页。
    导入方法
    1. 点下方「导出首页」，得到 RexHome.rex（写法跟 Mac 版 Rex 导出的一样）。
    2. iPhone／iPad：在下载或「文件」App 里点开 RexHome.rex，选择用 Rex 打开；或在 Rex 长按打开菜单 →「导入配置」选它。
    3. Mac：RexHome.rex 在「下载」文件夹，用 Rex 的「导入配置」选它。
    4. 在 claude.ai 打开时只能存成 RexHome.zip：先在「文件」长按改名为 RexHome.rex，Rex 不支持直接导入 .zip。
    同一个模块可以加好几行，例如地区剧一行韩国、一行日本。
    分享自己的首页：Mac 版 Rex 可以直接导出。iPhone／iPad：Rex 设置 →「iCloud」→「导出本机备份」→ 用上方按钮打开备份 zip（不用解压）→ 导出首页。别人的文件也可以先在这里打开检查一次再转发。
