Rex首页导出工具

作者：Bolinxxlin

iPhone 的 Rex 没有导出，用这里从备份导出首页；也可以打开别人的首页，或从默认首页开始，勾选行、调整顺序和设置，再导出分享。导出的首页读取 GitHub 上的加密脚本，不含明文。

可打开 Mac 导出或别人分享的 .rex，或 Rex 备份里的首页设置（payload/homes/configs 里没有 .sync 的 .json）。只在本机读取，不上传。
    导入方法（iPhone）
    1. 点下方「导出首页」，得到 RexHome.rex。
    2. 在下载或「文件」App 里点开 RexHome.rex，选择用 Rex 打开导入。
    3. 在 claude.ai 打开时只能存成 RexHome.zip：先在「文件」长按改名为 RexHome.rex，Rex 不支持直接导入 .zip。
    同一个模块可以加好几行，例如地区剧一行韩国、一行日本。
    分享自己的首页：Mac 版 Rex 可以直接导出。iPhone：Rex 备份 → 解压 → payload/homes/configs → 用上方按钮打开没有 .sync 的 .json → 导出首页。别人的文件也可以先在这里打开检查一次再转发。
