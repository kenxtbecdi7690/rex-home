# Rex首页

Rex 的影视首页模块，共 **11 个模块：7 大影片分类 + 豆瓣榜单 + 3 个功能模块**。默认读取 TMDB 片库，全部年份、最新在前，每行每页 200 部，可一直翻到来源尽头；首页各行互不重复（豆瓣榜单保持完整排名，除外）。

## 安装

| 文件 | 用途 |
|---|---|
| [`iphone.rex`](https://raw.githubusercontent.com/kenxtbecdi7690/rex-home/main/iphone.rex) | 模块订阅，指向下面的加密脚本，发布新版后 Rex 会提示更新 |
| [`rex-home.js`](rex-home.js) | 加密后的模块脚本（`REXENC` 格式） |
| [`RexHome.rex`](RexHome.rex) | 首页布局包，导入后直接得到下图的首页；不含明文，读取上面的加密脚本 |

`RexHome-v96.rex` 是旧版布局，仅留作备份。

## 首页布局

轮播 → ▶️ 接着看 → 剧集 → 地区剧 → 电影 → 动漫 → 综艺 → 纪录片 → 演唱会 → 豆瓣榜单，共 10 行。国内平台与片库筛选默认关闭，可在 Rex 里打开。

## 代理规则

给接手维护的人与 AI 代理（Claude 等）。改动前先读完这一节。

**分支与文件**
- 明文只放草稿分支 `rex-home-v130`，每版一个目录：`vN-draft/rex-home-vN.js`（明文脚本）与 `vN-draft/RexHome-vN.rex`（首页布局，内含明文脚本，仅供测试）。两个文件都要有。
- `main` 只放发布文件：加密的 `rex-home.js`、`iphone.rex`、`RexHome.rex`，以及本说明与工作流。**不要把明文提交到 `main`。**
- `main` 上的这三个发布文件只由工作流更新，不要手动修改，也不要自己调用加密服务。

**新版本**
- 从上一版复制，版本号 N 加 1，以下几处一起改：第一行 `// Rex首页 vN · 作者：Bolinxxlin`；`WidgetMetadata` 的 `id`（`rex.home.unified.vN`）与 `version`（`YYYY.MM.DD.N`，北京时间日期）；`RexHomeVer='vN'`；脚本末尾备用元数据里的 `id` 与 `version`；`RexHome-vN.rex` 布局里每行的 `widgetId` 与 `widgetBundleId`。
- 草稿提交信息写成 `新增 Rex 首页 vN 草稿：要点`，冒号后的要点会成为发布提交信息。
- 标题与选项用简体中文。

**必须保持的规则**
- 每个分类默认每页 200 部（轮播最多 20 张），保留 `page` 参数可翻页，读到来源尽头才停。
- 默认全部年份、按首映／首播时间从新到旧；年份选单从新到旧。
- 首页不重复：各行默认开启去重，剧集只出大陆剧，外国剧交给地区剧；去重后不足也不补回重复影片。唯一例外是豆瓣榜单：原榜排名、不参与去重。
- 剧集、电影、动漫、综艺、纪录片、演唱会之间按类型互斥，不让同一部片同时属于两类。

**提交前检查**
- `node --check vN-draft/rex-home-vN.js`，并确认第一行与版本号一致。
- 用模拟的 `Widget.tmdb` 把每个模块的每个下拉选项跑一遍：TMDB 片库模式都要有片、不报错；豆瓣模式在没有网络时报“格式异常”属正常。
- 首页各行按布局顺序跑一遍，统计重复应为 0（豆瓣榜单除外）。
- 改完后在上面的「更新事项」补一行；模块、类型、地区或榜单数量有变时，同步更新开头的模块总数与「分类总览」。

**发布**
1. 把草稿推到 `rex-home-v130`。
2. 在 GitHub 的 Actions 运行「加密并发布 Rex 首页」，两格留空即取最新草稿。工作流会加密、校验、更新 `rex-home.js`、`iphone.rex`、`RexHome.rex` 并提交到 `main`；同一版重复运行只会跳过，不会报错。
